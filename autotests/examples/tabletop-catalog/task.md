# Каталог настольных игр

## Сайт

Каталог настольных игр «Кубикаталог»: сетка карточек и стрелки
навигации по страницам. Все данные хранятся прямо в странице, страницы
переключаются на клиенте без перезагрузки.

- в каталоге 25 игр, на одной странице показывается 5 - всего 5 страниц;
- порядок игр фиксированный;
- у каждой игры есть: картинка, название, описание и цена;
- под каталогом - индикатор вида «Страница 1 из 5» и кнопки
  «← Назад» / «Далее →»; на первой странице «Назад» неактивна,
  на последней - «Далее».

## Что проверить

1. `test_page_contains_five_games` - на странице показано ровно 5 игр.
2. `test_all_cards_have_images` - у каждой карточки есть изображение
   с непустым src.
3. `test_page_indicator` - индикатор показывает «Страница 1 из 5».
4. `test_next_button_advances_page` - по кнопке «Далее» открывается
   вторая страница: индикатор показывает «Страница 2 из 5»
5. `test_navigation_limits` - на первой странице «Назад» неактивна,
   после четырёх нажатий «Далее» индикатор показывает «Страница 5 из 5»,
   и «Далее» неактивна.
