## Структура

```text
tourism/
├── README.md
├── task.md                  # условие и список проверок
├── solution.py              # эталонные Selenium-тесты
├── template.py              # шаблон тестов без решения
├── build-js.mjs             # генератор итоговых app.js
├── src/js/                  # редактируемые исходники JavaScript
│   ├── data.js              # данные и состояние
│   ├── core.js              # DOM и общие функции
│   ├── catalog.js           # каталог, поиск и карточка тура
│   ├── reviews.js           # отзывы
│   ├── auth.js              # авторизация
│   ├── bookings.js          # бронирования и оплата
│   ├── account.js           # профиль и администрирование
│   └── app.js               # события и запуск приложения
├── reference/               # исправная версия сайта
└── testcases/
    ├── 1/                   # контрольная исправная версия
    └── 2–16/                # версии с отдельными дефектами
```

## Возможности сайта

- поиск туров по направлению;
- просмотр подробной информации о туре;
- вход под пользователем или администратором;
- создание и отмена бронирования;
- имитация оплаты;
- добавление отзывов;
- изменение имени пользователя;
- добавление тура администратором;
- восстановление состояния после обновления страницы.

Для очистки `localStorage` и возврата к исходному состоянию доступна функция:

```js
window.GorizontMock.reset();
```

## Локальный запуск

Из корня репозитория выполните:

```bash
python -m http.server -d autotests/tasks/tourism/reference 8080
```

<http://localhost:8080>.

Для запуска определённого тест-кейса замените `reference` на его каталог, например:

```bash
python -m http.server -d autotests/tasks/tourism/testcases/6 8080
```
